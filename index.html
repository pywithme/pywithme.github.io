with python:

欢迎来到 pywith.com 交互式 Wasm 沙盒。你可以在下方的控制台直接输入 Python 代码（支持标准库及 NumPy 等科学计算），体验纯前端的实时执行：

with python as starter:
    basic = "语法与基础"
    builtin_func = "内置函数剖析"
    class_oop = "面向对象设计"
... as low_level:
    cpython = "底层源码与 GIL"
    frame = "执行帧与字节码"
